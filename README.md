# Hexly React Labs

A showcase of React and TypeScript laboratory assignments and practical front-end projects, featuring a monochrome interface inspired by GitHub and shadcn/ui.

## Live Demo

- **GitHub Pages:** [https://hdmi1519.github.io/hexly_react/](https://hdmi1519.github.io/hexly_react/)

## Projects & Labs

- **Module 00: React Components (`/tasks/components`)**
  - Pure JSX functional components without hooks.
  - Interactive preview and source code tabs: `Greeting`, `TaskList`, `ActionButton`, `ProfileCard`, `ImageGallery`.
- **Project 01: Emoji Finder (`/projects/emoji-finder`)**
  - Figma layout implementation.
  - Flexbox and CSS Grid layout with instant search and keyword filtering.
- **JavaScript Practice**
  - String, array, and loop algorithms repository link.

## Tech Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite 8
- **Styling:** Tailwind CSS v4 + DaisyUI
- **Routing:** React Router v7
- **Deployment:** GitHub Pages via GitHub Actions

## Getting Started

### Prerequisites

- Node.js (>= 20)
- npm or bun

### Installation

```bash
git clone https://github.com/hdmi1519/hexly_react.git
cd hexly_react
npm install
```

### Development

Start the local dev server:

```bash
npm run dev
```

### Build

Compile TypeScript and build the production bundle:

```bash
npm run build
```

### Preview

Preview the production build locally:

```bash
npm run preview
```
