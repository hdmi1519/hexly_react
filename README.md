# Hexly React Labs

A showcase of React and TypeScript laboratory assignments and practical front-end projects, featuring a monochrome interface inspired by GitHub and shadcn/ui.

## Live Demo

- **Production:** [https://hdmi1519.github.io/hexly_react/](https://hdmi1519.github.io/hexly_react/)

## Projects & Labs

- **Practical Work #0: JavaScript Practice**
  - String, array, and loop algorithm challenges ([GitHub Repository](https://github.com/hdmi1519/hexly_js_practice_tasks)).
- **Practical Work #1: React Components (`/#/tasks/components`)**
  - Pure JSX functional components without hooks.
  - Interactive preview and source code tabs: `Greeting`, `TaskList`, `ActionButton`, `ProfileCard`, and `ImageGallery`.
- **Project #1: Emoji Finder (`/#/projects/emoji-finder`)**
  - Figma specification layout implementation.
  - Flexbox and CSS Grid layout with instant search and keyword filtering.

## Tech Stack

- **Framework:** React 19 + TypeScript
- **Package Manager:** Bun
- **Bundler:** Vite 8
- **Styling:** Tailwind CSS v4 + DaisyUI
- **Routing:** React Router v7 (HashRouter)
- **CI/CD:** GitHub Pages via GitHub Actions

## Getting Started

### Prerequisites

- [Bun](https://bun.sh/) (recommended) or Node.js (>= 20)

### Installation

```bash
git clone https://github.com/hdmi1519/hexly_react.git
cd hexly_react
bun install
```

### Development

Start the local dev server:

```bash
bun dev
```

### Build

Compile TypeScript and build the production bundle:

```bash
bun run build
```

### Preview

Preview the production build locally:

```bash
bun run preview
```
